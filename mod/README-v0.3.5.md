# Kingdoms & Claims v0.3.5 — War Table Layout Hotfix

Forge 1.20.1 / Java 17. Replaces v0.3.4. Back up your world first.

- Fixed the army summary, order heading and command buttons drawing on top of each other.
- Army roster scrolling arrows now sit in the roster header, away from the summary panel.
- Status text is clipped and placed in a dedicated area above the scrollable order controls.
- Orders have a visible range indicator and scroll separately from the army roster.
- Slightly increased initial map zoom to make explored terrain easier to see.
- Retains all existing armies, kingdoms, towns, saved map data, tactical orders, and crafting recipes.

Testing: open the War Table with no armies, create multiple armies, select them, scroll the roster, scroll the commands, change GUI scale, resize the window, and verify that nothing overlaps.

This is a GUI layout repair, not a new terrain engine.
