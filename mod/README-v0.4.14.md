# Kingdoms & Claims v0.4.14 — Build Library / 3D Planner

- Open the 3D Kingdom Planner from anywhere inside your own claimed territory with BUILD permission using `/planner`, `/kingdom planner`, or Shift+K. The normal K territory map is unchanged.
- War Map no longer occupies the 3D planner sidebar; access the military map from the War Table.
- Builds are stored in categorized folders (Houses, Roads, Farms, Workshops, Defenses, Decor, Other) with up to 16 custom folders per faction. Existing v0.4.13 blueprints retain their saved blocks and are auto-categorized when loading older saves.
- Buildings > Folder cycles collections; choose the desired plan; Move to cycles the destination; Move selected design re-files it. Create folder accepts a 2-22 character name. All folder mutations are server permission-checked and persisted.
- Houses, roads, bridges, walls and other structures all use the existing first-person hologram and staged construction system.

Build with Java 17 + ForgeGradle for Forge 1.20.1. Back up your world before upgrading. Build success does not replace Minecraft gameplay testing.
