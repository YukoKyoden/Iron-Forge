# Kingdoms & Claims v0.4.6: Kingdoms-and-Castles-style City Planner

- Correct A/D strafe inversion from v0.4.5.
- Full-width HUD and 5-button strategy bar with the live Minecraft world in view.
- Camera controls: WASD, Q/E, mouse wheel, right-drag panning, middle-drag rotation.
- Click Zone Land to enter in-world zoning mode. Select claimed chunks on real 3D ground with click-and-drag, choose one of four district types, name it, and create it or add painted chunks to an existing district.
- Colored world-space chunk outlines for planned, selected, existing and hovered plots.
- Existing Districts, Economy, War Map editors are unchanged and still use server-enforced permissions and costs.
- No blueprint placement yet; this builds the essential city-strategy interactions.
- No terrain/blocks are changed by selecting zone outlines; no real player movement.

Backup world and replace old mod JAR; client and server should use the same version.
