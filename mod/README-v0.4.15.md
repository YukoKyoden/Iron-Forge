# Kingdoms & Claims v0.4.15 — Architect Folder Flyout & Repeat Placement

- Esc cancels the selection highlight even when Minecraft opens the pause menu first. In Save Blueprint, Esc fully cancels; Adjust Selection keeps the work-in-progress selection.
- Architect uses a folder list in the right dock; hovering a folder reveals saved blueprints in a flyout to the left. Click a blueprint to start placement; right-click one to select it for moving. Scroll each list independently.
- Repeat placement ON by default: after each successful server-authorized construction order, the translucent blueprint stays active. Press M to switch to single-placement. Esc ends placement. A short click cooldown and an aim-elsewhere requirement prevent accidentally building twice in one place.
- 96-block range, progressive construction, saved housing estimates, claim protection, and material checks remain.
